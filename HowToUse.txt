LANGAI — ИНСТРУКЦИЯ ПОЛЬЗОВАТЕЛЯ
================================

1. НАЗНАЧЕНИЕ ПРИЛОЖЕНИЯ
------------------------

LangAI — локальное приложение для Windows, предназначенное для изучения переводов предложений.

В приложении можно:
- добавлять предложения по одному или списком;
- переводить одно предложение на несколько языков;
- объединять предложения по темам;
- создавать упражнения автоматически или вручную;
- редактировать перевод, позиции слов, варианты ответов и подсказки;
- прикреплять собственные аудиофайлы;
- создавать озвучку через ElevenLabs;
- практиковать отдельно выбранный язык и тему;
- пользоваться уже подготовленными упражнениями и аудио без подключения к интернету.


2. УСТАНОВКА
------------

1. Запустите файл LangAI_0.1.0_x64-setup.exe.
2. Следуйте указаниям установщика.
3. Запустите LangAI через меню «Пуск» или ярлык приложения.

Если Windows SmartScreen покажет предупреждение о неизвестном издателе, нажмите:
«Подробнее» → «Выполнить в любом случае».

Предупреждение появляется из-за отсутствия коммерческого сертификата цифровой подписи и само по себе не означает, что в файле обнаружена угроза.

Системные требования:
- Windows 10 или Windows 11;
- 64-разрядная система;
- Microsoft Edge WebView2 Runtime (обычно уже установлен в современных версиях Windows);
- интернет для генерации переводов и озвучки.


3. ПЕРВОНАЧАЛЬНАЯ НАСТРОЙКА
---------------------------

Откройте раздел «Настройки».

Для автоматического создания переводов необходим собственный ключ OpenAI API.
Для автоматической озвучки необходим отдельный ключ ElevenLabs API.

Ключ ElevenLabs не обязателен, если озвучка не нужна или пользователь добавляет собственные аудиофайлы.

API-ключи сохраняются в защищённом хранилище учётных данных Windows. После сохранения приложение не показывает их полный текст.

ВАЖНО:
- не передавайте API-ключи другим людям;
- не отправляйте ключи в переписке и не публикуйте снимки экрана с ключами;
- расходы OpenAI и ElevenLabs оплачиваются владельцем соответствующего аккаунта;
- стоимость и лимиты определяются самими сервисами и могут изменяться;
- подписка ChatGPT не равна балансу OpenAI API: оплата API настраивается отдельно.


4. КАК СОЗДАТЬ OPENAI API-КЛЮЧ
------------------------------

1. Откройте https://platform.openai.com/ и войдите в аккаунт OpenAI.
2. При необходимости создайте проект.
3. Откройте страницу API Keys:
   https://platform.openai.com/api-keys
4. Нажмите кнопку создания нового секретного ключа.
5. Выберите проект и необходимые ограничения ключа.
6. Скопируйте ключ сразу после создания и сохраните его в безопасном месте.
7. Проверьте раздел Billing и убедитесь, что для API настроена оплата или доступен баланс.
8. В LangAI откройте «Настройки» → «OpenAI API».
9. Вставьте ключ и нажмите «Проверить и сохранить».
10. Выберите доступную модель и нажмите «Сохранить модель».

Если список моделей не загрузился:
- проверьте интернет;
- убедитесь, что ключ скопирован полностью;
- проверьте баланс и ограничения проекта;
- при необходимости создайте новый ключ.

Официальная инструкция OpenAI:
https://platform.openai.com/docs/quickstart/make-your-first-api-request


5. КАК СОЗДАТЬ ELEVENLABS API-КЛЮЧ
----------------------------------

1. Откройте https://elevenlabs.io/ и войдите или зарегистрируйте аккаунт.
2. В боковом меню откройте «Developers».
3. Перейдите на вкладку «API Keys».
4. Создайте новый ключ и задайте ему понятное имя, например LangAI.
5. Разрешите ключу доступ к Text to Speech и просмотру голосов.
6. При желании установите для ключа лимит расходов/кредитов.
7. Скопируйте ключ сразу после создания. Позже ElevenLabs не покажет его полностью.
8. В LangAI откройте «Настройки» → «ElevenLabs API».
9. Вставьте ключ и нажмите «Проверить и сохранить».
10. Выберите голос из загруженного списка и нажмите «Сохранить голос».

Официальная инструкция ElevenLabs:
https://help.elevenlabs.io/hc/en-us/articles/14599447207697-How-do-I-authorize-myself-using-an-API-key


6. ДОБАВЛЕНИЕ И ПОДГОТОВКА ПРЕДЛОЖЕНИЙ
--------------------------------------

1. Откройте раздел «Предложения».
2. В поле «Перевести на» выберите язык перевода.
3. При необходимости укажите тему, например «Отпуск», «Работа» или «Путешествия».
4. Введите одно или несколько предложений. Каждое новое предложение вводится с новой строки.
5. При необходимости добавьте комментарий для нейросети, например:
   - «Переведи разговорно»;
   - «Используй британский английский»;
   - «Раздели предлоги на отдельные позиции»;
   - «Используй сленговый вариант».
6. Нажмите «Добавить».
7. Выберите нужные предложения флажками и нажмите «Подготовить выбранные».

Одно исходное предложение может иметь переводы на нескольких языках. Чтобы добавить ещё один язык без создания дубликата:
1. выберите существующее предложение;
2. выберите новый язык в поле «Перевести на»;
3. нажмите «Подготовить выбранные».

Фильтры языка и темы влияют только на отображение списка и не удаляют данные.


7. КАРТОЧКА ПРЕДЛОЖЕНИЯ И РУЧНОЙ РЕДАКТОР
-----------------------------------------

Нажмите «Карточка и перевод» возле предложения.

В карточке отображаются:
- исходное предложение;
- темы;
- готовые языки;
- полный перевод;
- позиции упражнения;
- правильный вариант каждой позиции;
- три неправильных варианта;
- необязательная подсказка;
- аудио выбранного языка.

В карточке можно:
- изменить готовый перевод;
- создать перевод для нового языка вручную;
- добавлять и удалять позиции;
- менять порядок позиций перетаскиванием за синюю ручку;
- изменить правильные и неправильные варианты;
- добавить подсказку;
- собрать строку перевода из правильных позиций;
- сохранить новую версию упражнения.

Итоговый перевод должен совпадать с правильными позициями, соединёнными по порядку. Для автоматического заполнения используйте кнопку «Собрать перевод из позиций».

Для каждой позиции требуется один правильный и ровно три разных неправильных варианта. Варианты не должны отличаться друг от друга только знаком препинания.


8. АУДИО И ОЗВУЧКА
-------------------

Аудио привязывается отдельно к каждому языку одного предложения.

Добавление собственного файла:
1. откройте карточку;
2. выберите язык;
3. нажмите «Добавить свой файл» или «Заменить файлом»;
4. выберите MP3, WAV, OGG, M4A или WebM размером не более 25 МБ;
5. проверьте запись кнопкой «Прослушать».

Создание озвучки через ElevenLabs:
1. сначала настройте ElevenLabs API и голос;
2. откройте карточку уже подготовленного перевода;
3. выберите нужный язык;
4. нажмите «Озвучить через ElevenLabs»;
5. дождитесь завершения генерации;
6. нажмите «Прослушать».

Новая запись заменяет прежнее аудио выбранного языка. После генерации файл хранится локально и воспроизводится без интернета.


9. ПРАКТИКА
-----------

1. Откройте раздел «Упражнения».
2. Выберите язык практики.
3. Выберите тему или оставьте «Все темы».
4. Нажимайте на варианты слов. Выбранный вариант вставляется в первый свободный пропуск.
5. Проверка выполняется автоматически после заполнения всех пропусков.

Если допущена ошибка, текущая попытка очищается целиком и предложение можно собрать заново.

После правильного ответа:
- показывается полный перевод;
- становится доступна кнопка «Прослушать», если для языка есть аудио;
- можно перейти к следующему предложению.


10. ЧТО РАБОТАЕТ БЕЗ ИНТЕРНЕТА
------------------------------

Без интернета доступны:
- просмотр библиотеки;
- фильтры языков и тем;
- редактирование и ручное создание упражнений;
- практика уже подготовленных предложений;
- проверка ответов и подсказки;
- прослушивание сохранённых аудиофайлов;
- добавление тем и локальных предложений.

Интернет необходим для:
- генерации или повторной генерации перевода через OpenAI;
- получения актуального списка моделей OpenAI;
- проверки API-ключей;
- получения списка голосов ElevenLabs;
- создания новой озвучки ElevenLabs.


11. ДАННЫЕ И КОНФИДЕНЦИАЛЬНОСТЬ
-------------------------------

Предложения, переводы, упражнения, темы и сведения об аудио хранятся локально на компьютере пользователя в базе SQLite. Аудиофайлы также сохраняются локально.

При автоматической подготовке текст предложения передаётся в OpenAI.
При автоматической озвучке готовый перевод передаётся в ElevenLabs.

Не добавляйте конфиденциальные, персональные или коммерчески чувствительные сведения, если их передача стороннему API не разрешена владельцем данных.

Разработчик приложения не управляет доступностью, тарифами, лимитами и правилами OpenAI или ElevenLabs и не несёт ответственности за перебои или изменения в работе этих сторонних сервисов.


12. УСТРАНЕНИЕ ПРОБЛЕМ
----------------------

Если перевод не создаётся:
- проверьте интернет;
- проверьте OpenAI API-ключ;
- проверьте баланс OpenAI API;
- выберите другую доступную модель;
- повторите подготовку предложения.

Если озвучка не создаётся:
- проверьте ElevenLabs API-ключ;
- сохраните голос в настройках;
- проверьте лимит кредитов ElevenLabs;
- убедитесь, что перевод уже подготовлен;
- повторите генерацию.

Если аудио не воспроизводится:
- попробуйте MP3 или WAV;
- замените повреждённый файл;
- перезапустите приложение;
- проверьте громкость Windows и устройство вывода.

При обращении по поводу ошибки приложите:
- версию Windows;
- версию LangAI;
- точное описание действий перед ошибкой;
- текст сообщения об ошибке;
- снимок экрана;
- информацию о том, повторяется ли ошибка после перезапуска.

Никогда не отправляйте разработчику API-ключи.

14. БЕЗОПАСНОСТЬ API-КЛЮЧЕЙ
---------------------------

- Используйте отдельные ключи только для LangAI.
- По возможности задавайте ограничения и лимиты расходов.
- При подозрении на утечку немедленно удалите ключ в кабинете соответствующего сервиса и создайте новый.
